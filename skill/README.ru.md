Попросите такой инструмент, как Claude, прочитать корейский документ — и **он напишет
собственный разборщик**. `.hwp` — двоичный формат, поэтому обратно обычно приходит
абракадабра или документ, из которого пропали таблицы.

Этот навык велит ему **вызвать `kayatext`** вместо этого.

---

## Сначала нужен kayatext

Навык — это только указание; саму работу делает `kayatext`.

[Скачать](../../../releases/latest) → распакуйте и положите в `PATH`.
Чтобы работал `.hwp`, `rhwp` должен лежать **в той же папке**.

```bash
sudo cp kayatext rhwp /usr/local/bin/
kayatext --version
```

## Установка

### Claude Code

```bash
mkdir -p ~/.claude/skills/korean-documents
curl -sL -o ~/.claude/skills/korean-documents/SKILL.md \
  https://raw.githubusercontent.com/kjh0523/kayatext/main/skill/SKILL.md
```

Чтобы использовать только в одном проекте, положите файл в `.claude` этого проекта, а не
в `~/.claude`.

### claude.ai

Настройки → Skills, загрузите `SKILL.md`.

## Проверка

В новой сессии попросите прочитать корейский документ.

```
Сделай сводку по этому файлу: протокол.hwp
```

**Если навык сработал**, он вызовет `kayatext протокол.hwp -`.
**Если нет**, инструмент попробует открыть файл через `olefile` на Python — значит,
навык не установлен.

## Что он предписывает агенту

- для `.hwp` `.hwpx` `.hml` `.xlsx` `.xlsm` `.docx` `.rtf` **не писать разборщик**, а
  вызывать `kayatext`
- **по умолчанию — Markdown.** При извлечении в простой текст таблицы превращаются в
  сплошной текст: в одном документе на 116 страниц их было 91
- если `kayatext` нет, **сказать об этом пользователю.** Не писать вместо этого
  разборщик и не выдавать испорченный результат — это не помощь, а неверный ответ
- если при преобразовании что-то выпало (фигуры, диаграммы…), **сообщить и об этом.**
  Если таблицы, бывшей в документе, нет в результате, отвечать так, будто он её прочитал,
  нельзя

Последние два пункта — главные. **Не давать ему делать вид, что он знает,** — вот
настоящий сбой, который этот навык призван предотвратить.

## Чего пока нет

`.pdf` `.pptx` `.doc` `kayatext` читать не умеет, и навык так и говорит.

Готовится MCP-сервер. Цель — чтобы им можно было пользоваться через `npx`, без установки.
